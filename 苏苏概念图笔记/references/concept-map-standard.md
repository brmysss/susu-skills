# 严格概念图标准

## 1. 定义

概念图是“概念节点 + 有方向的关联词 + 概念节点”组成的命题网络。它模拟知识在大脑中的网络结构，能够表达层级、因果、条件、组成、对立、证据、促进、阻碍等不同关系。

它不等于：

- 思维导图：主要表达分类和从属。
- 流程图：主要表达步骤、状态或时间顺序。
- 文章结构图：主要复述章节目录。
- Obsidian 关系图谱：通常只能表达“存在链接”，不能准确说明关系是什么。

判断一张图是否为概念图，最简单的方法是沿任意一条边朗读：如果不能得到一句明确命题，它就不是合格的概念图边。

## 2. 概念与概念笔记

- 一个节点对应一个概念；一张概念笔记负责把这个概念“解压缩”。
- 多张概念笔记通过概念图组合成知识体系。
- 图负责导航和表达内部逻辑，笔记负责定义、解释、证据、例子和边界。
- 阅读时可以先做概念笔记；积累后再画概念图。生成式工作流则应先保留完整命题清单，再生成压缩后的主图。

## 3. 方向、关联词与交叉连接

- 箭头代表阅读方向，不必只有一个起点。
- 关联词可以是动词、介词结构或短句，只要能准确说明关系。
- 允许跨分支连接。跨链连接往往比树状层级更能体现真正理解。
- `A → B → C` 只有在两条边都分别构成命题时才成立；否则改写为 A 直接指向 C，或使用“通过……”说明中介机制。

## 4. 密度与升维

主图需要同时满足“一眼了解全文”和“不是梗概”。默认采用中密度：

- 35–45 个唯一概念节点，目标约 40。
- 3–5 条能够回答焦点问题的解释路径。
- 2–4 个最有解释力的证据节点。
- 完整命题清单作为图外语义底稿，不受主图节点预算限制。

升维是把已经理解的局部网络压缩成一个更高层概念。只有当读者看到该概念能够还原局部网络时才适用。压缩不能切断关键推理，也不能把多个不同关系模糊成“相关”。

## 5. 以用户为主

- 不复制作者目录或句子，而是用自己的话重建概念与关系。
- 保留对用户理解主题有价值的知识，不追求逐段覆盖。
- 区分材料所说、证据所支持和制图者的推断。
- 图是思考工具，可持续修正；最终价值在于能沿一个概念联想到相连概念。
