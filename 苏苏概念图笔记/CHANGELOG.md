# Changelog

本文件记录「苏苏概念图笔记」的公开版本变化，版本号遵循语义化版本规范。

## [1.0.2] - 2026-07-29

### Fixed

- 明确 Mermaid Markdown 是必交正式成品，PNG 仅为可选增强。
- 缺少 Playwright、Chromium 或 Mermaid CLI 时直接跳过 PNG，不再阻塞任务。
- 禁止智能体仅为生成 Mermaid 擅自安装浏览器或依赖；只有用户明确要求 PNG 并授权时才能询问安装。
- 增加无渲染器环境下的静态语法审计与交付说明。

## [1.0.1] - 2026-07-29

### Changed

- 将默认 Mermaid 布局调整为更紧凑的横向间距与更清晰的纵向层距。
- 增加宽高比质量门槛：默认目标 `1.6–2.0`，超过 `2.2` 必须重新布局。
- 明确禁止通过缩小字号掩盖过宽问题，优先调整层级、根节点和间距。

## [1.0.0] - 2026-07-29

### Added

- 建立严格概念图定义，以“概念—关联词—概念”的可朗读命题作为硬标准。
- 默认交付完整命题清单、中密度 Mermaid 主图和 PNG 渲染预览。
- 将中密度主图控制在 35–45 个唯一概念节点，目标约 40 个。
- 增加概念笔记下钻、图外解压缩、语义配色和升维压缩规则。
- 增加 Mermaid 独立渲染脚本、三组评测场景及输出契约。
